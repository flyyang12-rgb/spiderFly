# DP 创建与自动试跑验证

日期：2026-09-11。当前工作区改动，未提交、推送或重启正式服务。测试源码位于隔离副本，正式数据库、任务和浏览器资料没有参与测试。

## 实现

- 新增可选 `drissionpage-v1`，保留原生 Python 和 DrissionPage 4.1.1.4；安装清单 `backend/requirements-dp.txt`。
- `dp_probe` 在串行队列中观察真实页面。`save_draft → test_collection` 保存及试跑；使用草稿保存任务后、候选版本验证、维护及正常执行均路由到同一 DP 执行器。
- 读取普通任务 `SPIDERFLY_BROWSER_PORT`，默认 9123。执行器启动本次无头 Edge/Chrome，先核对资料目录归属，再允许脚本连接。端口占用明确失败，不接管；普通任务仍沿用原有等待流程。
- 独立检查网络响应、产物字段、数量和冻结验收；日志返回实际地址。停止和超时只结束本次进程树。每次新匿名资料目录，不继承探索登录态。
- DP 是具有宿主机账号权限的原生子进程，不是 WSL 沙箱。源码检查只防常见端口和生命周期配置错误，不构成 Python 安全隔离。

## 真实 AI 验证

提示：用 DP 创建知乎周榜前五条采集任务并自动试跑，输出排名、标题、问题链接、来源网址；先查知识库，使用普通任务端口。

实际链路：程序附带知识 → 模型主动 `read_knowledge` 两次 → `dp_probe` → `save_draft` → `test_collection` → 回复结果。

使用 deepseek-v4-pro，共 6 次模型调用，07:56:48–07:57:21 UTC，约 33 秒。模型未主动调用 search_knowledge；主动补读当前 DP 执行模板。未切换 Scrapling 或 Playwright 探索工具。

草稿实际使用 DrissionPage，试跑成功返回 5 条，结果文件 `zhihu_week_top5.csv`。DP 页面检查和试跑均使用 **127.0.0.1:9123**。来源为 `https://www.zhihu.com/knowledge-plan/hot-question/hot/0/week`。独立核对五个标题在 DP 观察文本中的顺序、排名 1–5、来源网址，均一致。页面检查的链接摘要限 60 个，不把截断摘要当作完整页面链接清单。

真实 AI 测试保存的是隔离草稿，没有创建正式用户任务。另用合成任务记录验证了保存后执行路径，同样获得五条并记录 9123。页面“使用草稿”仍是新任务保存入口；已有任务更新保持候选验证与确认流程。

## 回归与修正

原生 DP 9 项专项检查通过，包括真实页面检查、队列试跑、保存后执行、停止释放端口、占用时不启动、版本路由和错误端口配置拒绝。全套回归 368 项：350 通过、18 条件跳过。最后补充拒绝直接传入端口的构造检查，专项再跑 6 通过、3 条件跳过；真实浏览器检查通过 `SPIDERFLY_TEST_DP=1` 单独启用。

联调修正：DP 4.1.1.4 的连接配置必须与已启动浏览器的无头模式一致，否则库可能关闭并尝试重连；平台及脚本模板统一使用 `existing_only().headless()`。页面正文改用 `page.ele('css:body').text`。早期 AI 轮次在缺少 DP 观察工具、观察接口错误时未完成，未计为成功；修正后重新做了完整模型验证。

证据位于仓库外 `spiderfly-dp-runtime-bc5bea09af9b40d7b6a7d5d902d6ed8f` 隔离目录：`dp-tests.log`、`final-tests.log`、`live-agent-third.log`、`live-result.json`、CSV。历史失败轮次另存。测试依赖仅安装到测试虚拟环境。
