# 界面布局与分组

按用户来到页面要完成的事情分组。筛选、操作和结果围绕同一对象排列，页面内容使用统一边界；沿用白绿风格。

## 主入口

| 入口 | 放在一起的内容 | 主要操作 |
| --- | --- | --- |
| 工作台 | 概况、当前队列、最近运行、异常提醒 | 进入任务或运行页面 |
| 任务中心 | 单任务和工作流定义、类型及名称筛选、可用状态 | 新建、AI 创建、编辑、运行、设置定时 |
| 运行中心 | 运行队列、定时计划、运行记录 | 查询计划、查看结果、进入日志和步骤 |
| 管理中心 | 管理配置、宿主机、操作审计 | 配置服务、管理人员与电脑、核对管理操作 |

工作台只展示摘要，保留队列、记录和异常区域内的相关入口，不再单独平铺新建任务、任务中心、定时计划和运行记录这一排重复快捷入口。创建、完整编辑、计划和历史从相应主导航进入。定时在任务创建/编辑中一起设置，也能从对象行或运行中心快捷修改；各入口共用定时字段和后端校验。

## 页面内的分组

| 页面 | 从上到下的顺序 |
| --- | --- |
| 任务中心 | 对象数量与新建操作 → 筛选 → 对象列表；三者在同一面板 |
| 运行记录 | 数量、记录范围与刷新 → 类型和其他筛选 → 结果列表 → 分页 |
| 管理配置 | 团队成员 → API 密钥配置与飞书通知；宽屏并排，窄屏顺排 |
| 操作审计 | 折叠的运行信息 → 操作记录 → 分页；每页 10 条，可查全部历史 |
| 宿主机 | 电脑列表及行内审批/调度 → 远程运行；接入操作、机器详情按需展开 |

运行记录保留任务执行与流程整轮两种身份，各自使用原查询和分页。开始、结束日期成组展示，切换记录类型保留各自筛选；窄屏收起筛选后保留输入，并先显示结果。表格需要横向滚动时，只滚动表格区域。

管理中心默认进入管理配置。成员、API 和飞书放在同页，仍分别沿用各自权限与保存动作；它们没有共同提交的事务。机器审批与调度模式留在宿主机。运行信息和操作审计同页，但运行信息保持只读。

宿主机以电脑列表为主体，概况缩为列表上方一行。默认显示待批准和已批准电脑；“全部电脑”可查看已拒绝、已撤销的登记。接入新电脑默认收起，点击后才显示生成接入码与安装包入口；机器标识、四项条件、版本和心跳在详情中，待批准标识始终紧邻审批操作。撤销接入放在详情内并保留确认。手机标题和提醒同排、工具栏同排，状态与原因成组，避免将短信息拉成长列。

业务执行记录关注脚本、流程、步骤和产物；操作审计关注谁进行了管理操作，两者各用原有入口。远程运行完整列表仍在宿主机，本轮没有扩展跨类型混排接口。

## 全局与对象操作

运行提醒和个人账号保留在全局区域。主控运行状态只在工作台、运行中心显示，并明确称为主控状态；它不代表所有 Agent 电脑的状态。

任务的运行、编辑和定时跟随任务；流程的顺序、整轮运行和触发记录跟随流程。删除、归档、停止及维护确认保留原对象和范围说明。错误、日志和产物不作为重复文字删除。

## 对应代码

[App.vue](../frontend/src/App.vue) 组织四个入口和公共内容边界；[constants.js](../frontend/src/lib/constants.js) 与 [useWorkspaceData.js](../frontend/src/workspace/useWorkspaceData.js) 负责导航。

[TaskCenterPage.vue](../frontend/src/features/taskCenter/TaskCenterPage.vue) 组合对象操作、筛选与列表；[RunHistoryPage.vue](../frontend/src/features/executions/RunHistoryPage.vue) 将类型选择交给两类记录的筛选区；[FilterSection.vue](../frontend/src/components/FilterSection.vue) 负责窄屏收起、展开和输入保留。

[ServiceSettingsPage.vue](../frontend/src/features/settings/ServiceSettingsPage.vue) 组合成员和服务配置；[AuditPage.vue](../frontend/src/features/members/AuditPage.vue) 组合运行信息与操作记录。功能权限和后端入口见[管理配置](服务配置.md)及[功能地图](功能地图/README.md)。
