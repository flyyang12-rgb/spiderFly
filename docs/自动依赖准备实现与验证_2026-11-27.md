# 自动依赖准备实现与验证

单个 Python 文件和项目 ZIP 都自动生成依赖清单。原静态分析保留导入分类、来源和约束，自动准备阶段将已知别名映射为安装包，条件导入直接纳入清单。普通未映射英文模块按同名发行包提交安装器，不以静态识别成功宣称实际安装成功。

cv2 默认对应 opencv-python，ONNX Runtime 和 PyTorch 默认使用普通发行包，已有 GPU 或 headless 清单优先。PaddleOCR 自动补充 PaddlePaddle，引擎和 OpenCV contrib 需求一并准备，避免默认 OpenCV 与 contrib 同时安装。

界面移除逐项处理方式、包名和排除理由表单，仅显示自动准备状态与可展开的只读依赖清单。保存后主控自动构建业务环境；远程任务沿用 Agent 安装及环境事实核验协议，无需修改 Agent。

主控为不同程序使用不同 venv 目录，业务解释器与平台 .venv 分开。Agent 继续使用冻结任务包哈希对应的环境缓存。未知动态表达式记录为运行时行为，平台不会运行上传代码来猜依赖，也不会为补包装作成功或擅自重复执行已产生副作用的任务。缺少包内业务文件仍报错。

## 验证

- 后端全套 860 项中 841 通过，19 条件跳过，Agent 104 项中 103 通过，1 条件跳过。
- 自动解析、单文件与 ZIP 上传、固定版本、GPU/headless 选择、PaddleOCR 引擎、已保存排除记录、动态导入及缺少业务文件等 56 项定向检查通过。
- 实际在隔离目录创建业务虚拟环境，自动下载并成功导入 OpenCV、ONNX Runtime、requests。第二个合成任务创建另一条虚拟环境路径，确认与平台解释器和第一项任务隔离。
- 实际安装使用 OpenCV 5.1.0、ONNX Runtime 1.32.0、requests 2.34.2，版本为本次安装结果，不作为生产强制固定版本。
- 隔离浏览器使用包含 cv2、onnxruntime、torch、paddleocr 的合成脚本和 ZIP，验证无需填写包名、保存按钮可用、清单正确、手机布局和控制台无错误。torch、paddleocr 及其推理引擎的实际完整安装没有在本轮下载验证。
- 现有不存在安装包的回归检查继续确认环境失败并阻止本机定时启动。

本轮不运行用户业务程序，不宣称业务结果通过。
