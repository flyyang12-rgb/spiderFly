# 每月一号与最后一天

每月定时只提供“每月一号”和“每月最后一天”，均按北京时间执行。创建、编辑、快捷设置、单任务和本机工作流共用这两个选项。月底自动使用当月实际天数，不再用 31 号代替月底。

## 规则与实现

| 要求 | 实现与核对 |
| --- | --- |
| 一个月只选月初或月底 | `PlanFields.vue` 新设置只提供一号、最后一天；不再展开 31 个日期 |
| 大小月、二月和闰年 | `scheduling.monthly_occurrence` 使用月历，统一计算下一次与最近一次；未来 5 次、任务触发和流程停机合并共用 |
| 保存后仍是月底 | `trigger_config.day` 使用 `1` 或 `"last"`；前端序列化、编辑回填、说明和运行日历保留该值 |
| 原日期不被意外改掉 | 已有 2～31 号计划显示“原计划：每月 N 号”；修改名称等字段仍保留原日期，主动选择一号或最后一天才变更；原日期缺失月份仍跳过 |
| 本机与 Agent | 主控负责计算计划点，沿用原目标路由和首次环境门控；Agent 协议及代码不变，无需升级 |
| 工作流 | 沿用整轮快照、同一计划点去重、忙碌跳过及停机合并；仍只支持主控本机 |
| 不改其他定时 | 每日、每周和旧 Cron 逻辑保持 |

例如每月最后一天 09:00，从 2027 年 1 月 31 日执行后，依次为 2 月 28 日、3 月 31 日、4 月 30 日；2028 年二月则是 29 日。

入口：[日期计算](../backend/app/scheduling.py)、[流程计划](../backend/app/services/workflow_schedules.py)、[共享表单](../frontend/src/features/schedule/PlanFields.vue)、[表单序列化](../frontend/src/lib/format.js)、[运行日历](../frontend/src/features/schedule/useSchedule.js)。
