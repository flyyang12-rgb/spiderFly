# 整体布局梳理（2026-10-15）

用户要求重新判断哪些内容应当放在一起。沿用四个主入口和白绿风格，以用户来到页面要完成的事情分组。完整归属与后续维护规则见[界面布局与分组](界面布局与分组.md)，总体需求升为 v1.5。

## 调整

- 工作台保留概况与摘要；快捷入口统一称为定时计划。
- 任务中心把对象数量、新建/AI 创建、筛选与列表归入一个面板；归档显示属于筛选，手机条件计数包含它。
- 运行记录把类型选择放入原有筛选，数量和刷新在上，结果与分页在下；日期范围成组，手机默认收起筛选。两类记录各用原查询与分页，切换保留输入和展开状态，键盘切换后恢复类型选择焦点。
- 管理中心默认进入管理配置；团队成员仍在 API 密钥和飞书通知上方，运行信息仍与审计同页。电脑与关联远程运行继续位于宿主机。
- 主体共用内容边界，队列与页头对齐。主控状态只出现在工作台和运行中心，明确其本机范围。删除队列与定时计划面板中的重复标题，保留状态、时区和操作。

本轮只改 12 个前端文件，其中新增 FilterSection.vue 处理手机筛选显示和输入保留；没有改后端、对象身份、保存契约、权限或通知规则。没有增加装饰动画，沿用按下、焦点、展开及减少动态效果设置。
