# 每日、每周、每月定时

日期：2026-10-21。用户要求把定时方式改为“每日、每周、每月”，不再展示 Cron 输入。当前代码、隔离验证、本机加载与 GitHub 发布分别记录。

## 行为与边界

| 要求 | 实现 |
| --- | --- |
| 三种定时方式 | 新建单任务、编辑单任务、新建/编辑工作流、快捷设置共用 PlanFields，仅提供每日、每周、每月 |
| 每月设置 | 选择 1～31 号和 HH:MM，北京时间；当月没有该日期时跳过，不移到月底 |
| 时间一致 | 未来 5 次和实际调度共用 scheduling；31 号、二月和跨年均按真实日历计算 |
| 主控与 Agent | 单任务均支持；路由与原目标一致，Agent 程序和协议无需升级 |
| 工作流 | 仍限主控本机；成员启用且手动，冲突双向拒绝；整轮快照、失败停止、忙碌跳过、停机合并保持 |
| 旧计划 | 原 Cron 继续执行，编辑时显示“保留原计划”，可主动改选新方式；不自动转换或迁移已有规则 |
| 表单状态 | 回填已保存日期和时间，手动/定时切换保留草稿；修正重新启用计划误回每日的问题 |
| 时间表 | 每月任务只出现在该月对应日期，缺少日期时不生成虚假计划点 |

每月是独立 trigger_type，配置为 `{"day":31,"time":"09:00"}`。后端严格校验整数日期和时间；每月单任务复用每日/每周的队列与首次环境门控，不加入旧 Cron 专属维护轮次。日期计算复用已有 Cron 纯计算函数，不改变 Cron 专属执行与结算规则。
