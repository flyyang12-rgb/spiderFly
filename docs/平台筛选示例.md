# 上传 Excel，筛出待处理订单

这个示例读取创建任务时上传的 Excel，只保留“状态”完全等于“待处理”的行，再另存一个结果文件。它组合已有的 `excel.read`、`table.filter_equals` 和 `excel.write`；各条指令的参数见[指令目录](指令目录.md)。

## 准备输入表

保存为 `.xlsx`，第一张工作表的第一行必须包含“状态”列。下面是三条虚构订单：

| 订单号 | 状态 | 金额 |
| --- | --- | --- |
| 00123 | 待处理 | 0 |
| 00124 | 已完成 | 19.5 |
| 00125 | 待处理 | 42.5 |

结果保留订单 `00123`、`00125`，共两行；沿用第一张工作表的名称，保留全部列及原来的行顺序，不去重。订单号需要保留前导零时，应在 Excel 中以文本存储。

“待处理”与“待处理 ”不相等，筛选不会替你去掉数据首尾的空格。没有匹配行也算成功，会生成只含原表头的结果；缺少“状态”列则报错。

只处理第一张工作表，第一行列名须为非空且不重复的文字。读取时列名去掉首尾空白，完全空行跳过；公式和 Excel 错误单元格会报错，需要先处理成有效数据。结果是新建的普通数据表，不复制源表样式、图片或其他工作表。其他限制见[指令开发起步](指令开发起步.md)。

## 管理员准备安装包

任务环境需要 Python 3.12 或更新版本。把 `0.1.1` 安装包放到 SpiderFly 根目录下的固定位置：

```text
release/instructions/spiderfly_instructions-0.1.1-py3-none-any.whl
```

包文件不随源码提交，换电脑时需要另行提供或按[构建说明](指令开发起步.md)生成。平台安装声明版本对应的本地文件；缺包会明确报错，不会去公网安装同名包。Pydantic、openpyxl 等第三方依赖仍按原有方式安装，通常需要联网。

已有姓名任务使用的 `0.1.0` 包继续保留；本例需要含筛选指令的 `0.1.1`。已有任务不会自动升级。

## 新建任务并运行

在“管理中心 → 创建任务”填写：

| 项目 | 填写内容 |
| --- | --- |
| 名称 | 指令集订单筛选示例；若已有同名任务，换一个名称 |
| 入口文件 | 上传 [instruction_excel_filter_task.py](../examples/instruction_excel_filter_task.py) |
| Python 依赖 | `spiderfly-instructions==0.1.1` |
| Excel 模板 | 上传要处理的 `.xlsx`，第一张工作表包含“状态”列 |
| 触发方式 | 手动 |
| 通知 | 体验时关闭成功、失败通知 |

上传这一个 `.py` 即可，指令代码由安装包提供。创建后等待“Python 就绪”，再到任务中心点击运行。若提示缺少本机指令包，先补齐上述文件，再使用“修复环境”。

页面沿用“Excel 模板”这个名称，本例把它当作输入数据。**文件和脚本在创建任务时保存，每次运行使用该任务保存的同一份内容**；漏传文件会失败，不会改用虚构样本。这个入口需要从 SpiderFly 任务运行，直接双击文件会缺少运行所需的信息。

## 下载输入和结果

进入“运行中心 → 运行记录”，打开本次记录，在“本次文件”里下载：

- `订单筛选示例/输入.xlsx`：本次实际处理的完整输入存档。
- `订单筛选示例/结果.xlsx`：筛选后的新表。

任务结束后才能下载，进度在浏览器下载列表查看。成功时业务结果为 `EXCEL_FILTER_DONE`；按上面的三行样本运行，应得到两行结果。零行命中也会成功，结果文件只保留表头。

缺列等写出前的数据检查失败时，业务结果为 `EXCEL_FILTER_FAILED`，已经完整保存的输入仍可下载，供检查列名和数据；这时没有结果文件。若在收到文件或复制输入之前就失败，可能没有输入存档。其他故障以本次说明为准，**有文件不代表业务成功**。

平台先把上传原件复制到公共工作区，任务再复制为本次输入存档，随后处理这份存档。上传原件不改写；公共工作区清理不会删除本次存档和结果。再次运行会新建执行记录，保留各次文件，不覆盖旧结果。

重要文件请下载保存；删除整项任务也会删除对应运行资料。下载入口、共享访问范围和常见提示见[平台指令示例](平台指令示例.md#到哪里看结果)。

## 换一张表，或改筛选条件

只换输入表时，使用同一入口和新的 `.xlsx`，另建一个不同名称的任务即可，保留旧任务的记录。

要改筛选条件，先另存一份入口文件，在副本中修改这两个常量：

```python
FILTER_COLUMN = "状态"
FILTER_VALUE = "待处理"
```

例如改成 `FILTER_VALUE = "已完成"`，就保留已完成的行。然后上传修改后的单个 `.py` 和输入表，另建不同名称的任务。列名必须在表头中存在，文字条件按原文精确匹配；其他值的比较规则见[指令目录](指令目录.md#按单列相等筛选表格)。

修改本地副本不会改变已经上传的旧任务；“编辑任务”不能替换旧脚本、依赖或输入文件。“修复环境”只按原有依赖声明重新安装，不会把旧任务改成新版本。筛选条件目前在代码中设置，页面没有新增条件填写项。

本页是操作指南，实际服务是否已更新需以宿主机部署为准；虚构样本跑通也不等于已完成真实业务验收。
