# AI 浏览器探索

AI 优先调用原生 Scrapling：先搜索入口，使用带 Chrome 指纹的 Fetcher 读取页面；静态响应缺少内容时切换无头 StealthyFetcher。根据真实快照定位字段、提取并累计结果，不要求先打开可见浏览器或先登录。需要交互时再使用独立浏览器点击、输入、滚动和切换页签。没有网页探测记录的拒绝答复会被要求补一次实际检查；预算用尽仍未检查时明确标为“尚未验证”。

Fetcher 不运行浏览器；DynamicFetcher 和 StealthyFetcher 在后台运行浏览器引擎。无头运行不等于可以读取任何需要登录的数据。工具记录会显示实际使用的引擎和响应状态。

连续筛选和滚动使用 `scrape_live_open` / `scrape_live_act`，底层为 Scrapling `AsyncStealthySession`，同一对话保留无头浏览器上下文。AI 可查看实际 JSON 接口的分页参数、数组路径、字段和记录数，再用 `scrape_json_extract` 提取；字段可使用文本组合或同站链接模板，按原条件筛选并去重。接口总数不等于合格岗位数量，分区汇总也不等于默认排序前100。

## 安装

在运行 SpiderFly 的 Windows 账号下，进入项目目录：

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-browser.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

然后按正常更新流程，空闲时备份并重启后端。浏览器在首次使用时启动，不随服务启动抢占窗口。缺少依赖或浏览器时工具会报告安装方法，不默默回退。默认使用 Playwright 安装的 Chromium；已有受支持 Edge 的宿主机也可设置 `SPIDERFLY_BROWSER_CHANNEL=msedge`。

浏览器需要运行在已登录、可交互的 Windows 桌面。平台默认自启任务使用已登录的宿主机账号。通过远程电脑访问 SpiderFly 的成员，仍需要宿主机上的人完成登录；当前没有网页内远程控制或验证码代办功能。

## 使用

### 只探索方法

可以输入：“自主探索这个网站的公开采集方式，少量样本验证即可，不用采满数量或生成脚本；说明实际观察、调整和未验证的部分。”

AI 按“观察 → 选择工具 → 执行 → 检查反馈 → 调整”继续工作。遇到失败时依据真实错误修正，不能仅凭网站名判断无法采集；原因没有验证就标为假设。后续可以要求复核已有记录，不必重新采集。这些要求写在 `backend/app/ai_agent.py` 的系统提示词及工具循环中，新对话会沿用，不依赖本次聊天提醒。

在“处理记录与用量”查看实际工具、引擎、HTTP 状态、错误和部分完成结果。原生 HTTP、无头浏览器和可见浏览器是不同执行方式，界面会按实际情况显示。真实验收见 [AI 自主探索验收](AI自主探索验收_2026-09-10.md)。

### 采集结果或生成任务

1. 在“AI 创建”描述网站、条件和数量，例如“采集某招聘网站杭州 RPA 工程师岗位，前 100 条，含公司、薪资和链接”。不必先给完整 URL。
2. AI 用 scrape_search 核实入口，再用 scrape_page、scrape_inspect、scrape_extract 读取并提取。过程出现在处理记录，页面显示“原生 Scrapling 采集”。只有确需交互时才打开可见浏览器。
3. 实际需要登录或验证时，AI 保留现场并停止模型循环。在宿主机独立浏览器完成后，点击“我已处理，继续”。继续会启动新一轮，先重新观察，不假定登录已经成功。
4. AI 使用 Scrapling 从真实 DOM 提取数据，核对样本后逐页累计，按指定字段（通常为职位链接）去重，到目标上限停止。页面可下载已提取 CSV，包括未完成时的部分结果。
5. “关闭浏览器”停止本对话 AI 并关闭该会话；结果保留。普通“停止”停止模型循环，浏览器仍可保留供后续对话使用。

记录选择器和字段必须来自实际页面。平台限制结构化提取字段为文本和链接，不执行模型提供的任意 JavaScript。CSV 中可能执行公式的文本加单引号保护。数量与主键检查不能代替城市、岗位相关性等业务判断，AI 必须核对这些条件。

## 会话与范围

- 沿用现有 Agent 框架；原生 Scrapling 负责 HTTP/无头采集和选择器提取，Playwright 提供需要交互时的独立浏览器。浏览器运行在独立线程的事件循环，兼容 Windows ASGI 事件循环；不接管个人 Chrome/Edge，不开放调试端口。
- 原生采集最多保留 8 个对话快照，闲置 30 分钟释放。HTTP 保持 TLS 验证，逐跳检查公开地址，默认不自动升级重试明确的 401/403/429。原生浏览器同样检查页面资源地址。已提取的数据持久保存，关闭后仍可下载。
- 每个对话独立上下文，Cookie 仅在内存会话保存。最多 3 个会话，闲置 30 分钟自动关闭。关闭窗口、服务重启后需重新登录，已提取数据和最后观察仍保留。
- AI 可探索与用户任务相关的公开网站及页面资源，浏览器请求支持页面正常搜索/筛选所需的方法；不发送消息、投递申请、购买或修改账号。密码由用户输入。
- 每次请求检查 HTTP/HTTPS 公网地址，不提供本机文件或内网访问工具。该浏览器是可信固定操作服务，不等同于 WSL 的内核沙箱及 DNS/IP 固定通道；不向模型开放任意代码、请求体、请求头或 Cookie。
- 普通浏览器网络观察返回近期请求的 URL、状态、类型和方法。原生持久会话另提供 JSON 结构、记录数及公开搜索/分页参数白名单；原始响应最多2MB、仅在会话内保留最近12项，模型通过固定字段选择工具提取标量，不读取请求头、Cookie、密码或私人联系方式。DOM 观察覆盖当前页签主文档，暂不提供截图给模型或跨 iframe 操作。
- 最近观察和累计行数进入下一轮上下文。旧页面压缩为地址、状态和短摘要，当前页面保留有上限的结构，避免重复堆积整页耗尽预算。每轮仍有时间、调用次数和 Token 预算。暂停等待人工时不继续消耗模型预算；继续是新一轮，用户仍可随时停止。
- 服务重启会清除内存中的网络响应。样本、最后观察摘要和工具事件仍保留，但不等于完整网络证据可恢复；复核时必须区分历史记录和当前重新验证的事实。
- 超级管理员可将每轮上限设为 2,000,000 tokens、128 次调用、7200 秒；默认仍为 100,000 tokens、16 次、900 秒。提高上限不保证完成，自动维护预算独立配置。
- 单页最多提取 500 条，累计最多 2000 条/8MB；字段与去重主键不能在同一数据集中混用，目标上限由 AI 按用户数量传入。结果按对话权限下载。使用相同字段和主键重新提取时会补齐已有空字段，不覆盖已有非空值；下一轮能看到已保存字段、主键和样本，避免误改字段或把空值说成完整。

## 与定时脚本的区别

浏览器探索不在 Windows 执行模型生成的业务代码。公开采集可将验证后的方法生成 Python 草稿，走原来的 `save_draft → test_collection → 使用草稿` 流程；浏览器实际发现的公开域名可交给静态读取和 WSL 试跑。

浏览器会话的登录状态**不会自动进入 collection-v1**。依赖登录的页面可以在当前会话中提取并下载，不能仅凭这个结果声称无人值守的定时采集已经实现。定时脚本仍使用原有队列、受限采集环境及独立验收。

## 开发验证

按 [开发与验证](开发与验证.md) 创建源码和数据隔离的副本，安装 `requirements-dev.txt`、`requirements-browser.txt` 和指定指令 wheel，安装 Chromium 后运行：

```powershell
$env:SPIDERFLY_TEST_BROWSER='1'
python -X utf8 -m unittest discover -s tests -p test_ai_browser.py -v
```

真实浏览器检查使用合成页面和合成登录 Cookie，不使用业务账号。检查暂停/继续、观察/操作、Scrapling 提取、主键去重、会话隔离、过期保留数据、角色权限及无证据拒绝后的纠正。完整测试结果与部署状态另见带日期的验证记录。

### 追加能力

只验证探索过程时，可提出“自主探索公开采集方式，少量样本即可，说明实际观察、调整与未验证部分”。AI 沿用现有 Agent 工具循环；在“处理记录与用量”查看实际调用、错误、引擎和数据响应。复核已有证据不强制重新访问网页，历史观察不代表当前状态已重新验证。

原生操作错误会区分浮层遮挡、不可见、控件不可用和窗口关闭；不向模型暴露原始请求、输入值或堆栈。最近40个已观察公开URL保存在会话状态中，帮助跨轮接续；访问记录不代表已完成采集。筛选条件和CSV结果独立持久保存。

BOSS特定经验位于 backend/ai_knowledge/boss_public_observations.md：实际接口字段、菜单层级、多选重置、推广层与推荐岗位的区分。它是带日期的探测线索，不是未来成功保证。

已观察清楚的重复筛选可用 `scrape_collect_options` 分批执行，每批最多 20 个真实选项；失败时返回已完成和剩余项，避免从头重做。`browser_refine_results` 可修正已有数据，筛选规则也约束后续提取，并支持撤销最近一次筛选。
