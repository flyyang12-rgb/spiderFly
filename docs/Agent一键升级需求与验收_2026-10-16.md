# Agent 一键升级需求与验收

日期：2026-10-16。来源：用户要求 Agent 升级无需每次输入命令。主改 SpiderFly，版本为 0.4.1，协议仍 v1，最低兼容 0.3.0；环境事实能力仍从 0.4.0 提供。

## 操作和范围

从主控宿主机页下载新包，在 Agent 电脑解压，双击“升级Agent.bat”，选择原安装目录后点击“一键升级”。首次升级后，托盘提供“升级 Agent…”入口，选择新 ZIP 即可。自定义数据目录在“更多设置”填写。

这是 Agent 本机显式操作。复用已有管理脚本、机器签名和主控事务；不新增远程推送、自动下载、凭据或无人值守升级。主控先更新，再升级其他电脑；不在主控电脑生产启动 Agent，不绕过原整机锁。

## 需求与实现逐项对齐

| 编号 | 需求 | 实现与结果 |
| --- | --- | --- |
| U01 | 不输入命令，旧版也能进入 | 新包 BAT 启动 WinForms；原目录选择、数据目录可调整；新版托盘入口 |
| U02 | 使用主控包，拒绝错误/旧包 | 主控白名单 23 文件 ZIP，含版本与逐文件 SHA-256；先限制大小、路径和链接，再暂存/校验；相同或更低版本拒绝 |
| U03 | 任务或回传未结束不升级 | 本地 journal 前后复核；主控有活动租约时拒绝；不强制结束任务 |
| U04 | 核对后不再抢到新任务 | 签名暂停与原领取事务竞争；心跳和 claim 同时核对升级租约，仅暂停这台机器 |
| U05 | 自动备份、升级并重启 | 复用 manage.ps1 Stop/Backup/Upgrade/Start；核对新 PID 版本；数据和程序备份分开 |
| U06 | 原身份、配置、历史和模式保留 | 不重新注册、不替换数据目录、不回退 journal；主控调度开关不变，本机调度模式随启动恢复 |
| U07 | 新版启动失败可恢复 | 校验旧程序快照，恢复固定程序清单并尝试启动旧版；不恢复失败时如实报错，保留日志和备份 |
| U08 | 失败和断网不永久停派发 | 原 token 幂等恢复；丢失暂停响应也尝试恢复；新版重连先恢复；窗口可重试，租约最长 30 分钟 |
| U09 | 界面少文字，过程可见 | 白绿窗口，仅目录/包/更多设置/状态/主按钮；忙碌禁止关闭，失败显示重试和日志 |
| U10 | 不削弱现有隔离和权限 | 机器签名只操作自身；用户 Cookie 无效；私有备份 ACL；原整机锁、Job、依赖安装和回传链路保持 |

哈希清单只校验完整性，不是发布者数字签名，包仍需来自可信主控。突然断电或 Windows 强制终止不承诺自动完成所有恢复；保留本次备份后按日志处理，不清空原数据目录。恢复旧版成功但仍断网时，可在升级窗口重试恢复派发，或等待租约到期。

## 验证证据

- 后端全套 776 项：757 通过、19 项既有环境条件跳过。新增 9 项[升级暂停测试](../backend/tests/test_agent_upgrade.py)，包含权限、重复请求、不同 token、过期、晚领取、撤销和竞争；原下载测试校验完整包清单/哈希。
- Agent 全套 72 项：71 通过、1 项 Windows 符号链接权限跳过。新增 10 项[升级测试](../agent/tests/test_upgrade.py)：真实 PowerShell 管理脚本与合成 Agent 子进程完成 ZIP 升级和启动失败恢复；验证身份配置保留、任务/回传阻挡、坏哈希/路径、旧版本、断网恢复及原生窗口按钮/异步完成/重试。
- 前端原 213 项和新增[升级状态检查](审查证据/Agent升级状态页面检查_2026-10-16.mjs)，构建 122 模块。主控页面显示“升级中 / 暂缓新派发”。
- [真实 HTTP 与 DPAPI 结果](审查证据/Agent一键升级签名实测_2026-10-16.json)：本机隔离主控、合成 DPAPI 身份、实际短进程 helper、暂停后不派发与幂等恢复，校验实际主控包的全部哈希。没有启动生产 Agent，也不是两机验收。
- [实际窗口预览](审查证据/Agent一键升级窗口_2026-10-16.png)由本次 WinForms 控件离屏绘制；按钮、忙碌时关闭保护和失败后重试由自动测试操作同一窗口验证。

Windows 验证中发现并修正：.NET Framework 的空备份参数、PowerShell 7 继承的模块路径、后台子进程持有管道使升级等待不结束、未选择目录时的原始参数错误。管理和升级子进程改为私有文件日志，停止等待只针对自身进程。

## 现场验收

电脑 A 主控更新后，在电脑 B 用原 Windows 账号下载和运行升级窗口。空闲升级应显示 0.4.1，主控仍为同一机器 ID，身份/历史和原模式保持；运行中或未回传时应拒绝升级。再做一次原目标任务，核对仅 B 执行、日志/产物和环境版本回传。断网/重连与实际浏览器/Excel 按[两机矩阵](多宿主机阶段7发布与双机验收.md)记录。本轮未替用户操作另一台电脑。
