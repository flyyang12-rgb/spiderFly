# 普通 OCR 与超时退出验证

## Paddle 环境

使用程序生成的白底中英文文字图片，加载本地 PP-OCRv6 检测和识别模型，不下载权重、不访问业务网站。核对的依赖是 PaddlePaddle 3.3.1、PaddleOCR 3.7.0、PaddleX 3.7.2，Windows CPU 推理。

| 设置 | 实际结果 |
| --- | --- |
| 默认 OneDNN 设置 | 模型正常加载，首次推理报 `ConvertPirAttribute2RuntimeAttribute` 不支持 `ArrayAttribute<DoubleAttribute>` |
| `enable_mkldnn=False`，CPU 线程数 2 | 两次均正确识别 `SpiderFly OCR test 2026` 和 `普通文字识别测试`，每次约 2.8～3.0 秒 |

这次复现定位到推理执行的兼容问题，安装缺包不是该错误的原因。[Paddle 官方仓库已有同类问题记录](https://github.com/PaddlePaddle/Paddle/issues/79749)；[官方 OCR 文档](https://www.paddleocr.ai/latest/en/version3.x/pipeline_usage/OCR.html)提供 `enable_mkldnn` 和 `cpu_threads` 设置。关闭加速的验证结论限于这次普通文字识别样例与记录的版本组合。

[ordinary_ocr_check.py](../sample_scripts/ordinary_ocr_check.py) 可复用这项检查。需要一个已安装上述依赖的 Python 环境、本地模型文件和支持中文的字体，不会安装或更改包。默认关闭 MKL-DNN，可用 `--mkldnn default` 对照原始设置。每次生成自己的文字图片并校对两次识别结果；失败返回非零退出码，结果保存为 UTF-8 JSON。

```powershell
python -X utf8 sample_scripts/ordinary_ocr_check.py --model-root "本地模型根目录" --output-dir "检查结果目录" --mkldnn off
```

模型根目录包含 `PP-OCRv6_medium_det` 和 `PP-OCRv6_medium_rec`，各自含 `inference.json` 与 `inference.pdiparams`。默认使用 Windows 微软雅黑，也可通过 `--font` 指定已安装字体。

## 真实进程超时与网页

[test_timeout_lifecycle.py](../frontend/tests/test_timeout_lifecycle.py) 使用临时数据库、工作目录和独立服务，通过真实 HTTP 接口上传普通 PY、ZIP 及后续任务，实际创建各自的托管 Python 环境。测试的本机时限设为 60 秒；复用真实执行器，由隔离测试驱动串行领取，未启动第二个正式调度器。

| 核对项 | 单个 PY | 项目 ZIP |
| --- | --- | --- |
| 执行记录耗时 | 60.13 秒 | 60.02 秒 |
| 结束状态 | `timeout`，结束时间已保存、退出码非零 | 相同 |
| 父、子、孙进程 | 三个实际 Python 进程的句柄均确认退出 | 相同 |
| 工作目录 | 已清空 | 已清空 |
| 后续排队任务 | 成功输出 `FOLLOWUP_OK` | 相同 |
| 网页结果 | 显示“运行超时”，运行编号正确，日志可打开 | 相同 |
| 持久收尾回执 | 旧普通手动执行不采用协调回执 | 进程、工作区、执行器返回和最终收尾均已确认 |

网页使用当前已发布的构建，没有模拟提交或结束响应。观察到提示包含“运行超过任务设置的 60 秒，已终止”；后续任务成功提示排在超时提示之后，原超时不会被覆盖。

运行测试需 Windows、Microsoft Edge、后端开发依赖和 Playwright，以及已构建的 `frontend/dist`：

```powershell
python -X utf8 frontend/tests/test_timeout_lifecycle.py
```

测试自动清除继承的项目设置并核对全部数据路径。以上验证覆盖主控本机 PY/ZIP 的真实进程退出、网页提示和后续执行，不代替远程 Agent 现场或其他业务程序的结果。

隔离回归：后端共 860 项，841 通过、19 条件跳过；Agent 共 104 项，103 通过、1 条件跳过。本次没有修改平台运行逻辑或前端构建，新增可复用的样例、真实生命周期检查和验证记录。
