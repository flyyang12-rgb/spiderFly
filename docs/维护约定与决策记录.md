### 2026-09-07：失败通知附图与上传脚本位置

任务最终通知新增默认关闭的“失败附带截图”。同时开启失败通知和截图后，普通失败、业务失败或超时在清理现场前尝试截取宿主机前台窗口，保存为本次文件并随同错误原因发送；截图或上传失败不覆盖原错误，成功和取消不截图。群 Webhook 附图还需要应用 App ID、App Secret、机器人能力和图片上传权限。隔离全套 350 项检查中 347 通过、3 项因 Windows 符号链接权限不足跳过，前端构建及管理员、普通成员页面流程通过；真实桌面截图和飞书实际附图送达尚未验证。

同时明确上传的 Python 入口默认存放在 `data/apps/<应用ID>/<原文件名>.py`，数据库持有绝对路径；`SPIDERFLY_APPS_DIR` 可覆盖根目录。运行资料不纳入 Git，不直接编辑 `data/apps/`，更新脚本通过页面另建任务；备份或迁移包含完整 `data/` 和 `.env` 指向的外部目录。
