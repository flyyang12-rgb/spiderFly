# 网页运行结束提示

手动点击“运行”后，页面以前只显示提交成功。任务在后台结束时，切回任务中心的用户容易漏看最终状态。本次增加按运行回执编号跟踪的网页提示。

## 行为

- 主控部署机与 Agent 的手动单任务分别跟踪，成功、失败、超时、停止显示对应结果。
- 提示包含任务名、运行编号和可确定的耗时，保留到用户关闭或点击“查看日志”。多条结果依次显示。
- 本标签页刷新后继续跟踪，未读结果也会恢复；保留最近 24 小时的最多 20 条回执。主动退出或更换账号时清除。
- 短任务即使在两次工作区刷新之间结束，也会查询原回执并提示。网络失败继续重试；Agent 状态待确认时继续等待，不推断为结束。
- 网页提示与飞书通知开关分别工作。既有历史、定时任务和流程的结果仍在对应运行记录中查看。

## 入口

- [跟踪运行回执](../frontend/src/features/executions/useRunFeedback.js)：身份隔离、刷新恢复、终态识别和日志入口。
- [手动运行](../frontend/src/features/tasks/useTasks.js)：收到主控或远程回执后登记。
- [工作区通知](../frontend/src/workspace/useWorkspaceData.js)与[提示组件](../frontend/src/components/ToastNotice.vue)：提示队列、保持显示、关闭和操作按钮。

## 验证

在独立副本和临时数据库中使用合成任务回执，不执行用户业务程序。浏览器检查覆盖四类结束结果、快速结束、切换页面、刷新、未读结果恢复、停止后日志入口、远程状态待确认、暂时请求失败、提示排队、手机宽度和退出清理。

回归脚本：[test_run_feedback.py](../frontend/tests/test_run_feedback.py)。先在 `frontend` 目录构建，再使用已安装后端开发依赖和 Playwright 的 Python，在仓库根执行 `python -X utf8 frontend/tests/test_run_feedback.py`。需要本机 Microsoft Edge；脚本自动清除继承的项目设置并断言所有运行资料指向临时目录。

同日补充 [真实 PY/ZIP 超时验证](普通OCR与超时退出验证_2026-11-28.md)：两项任务实际运行 60 秒后超时，父、子、孙进程退出，后续任务成功；浏览器读取真实 API，确认超时提示和日志入口。
