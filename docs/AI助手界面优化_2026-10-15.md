# AI 助手界面优化（2026-10-15）

按用户指定的 [oil-ui](https://github.com/oil-oil/oil-ui) 整理现有 AI 对话界面。保留 SpiderFly 白底、绿色主色、系统字体和现有导航，优先展示正文与当前操作，草稿按需打开。参考副本版本为 0.23.0，提交为 `2d34e30f8973b6c083f9bdbfe85653022975fa0d`，未全局安装。

## 调整

- 去掉 TASK STUDIO、TASK COPILOT、OUTPUT、副标题和重复的用户身份标签，取消每条回复的边框、阴影和侧边色条。
- AI 回复完整排版为段落、列表、表格和代码块。新增 `marked`、`dompurify`，禁止执行消息 HTML、加载嵌入内容和远程图片；链接在新页打开并限制页面引用。用户输入和 Python 源码继续按文字显示。安全要求见 [Marked](https://marked.js.org/) 与 [DOMPurify](https://github.com/cure53/DOMPurify)。
- 有实际草稿或探索结果时才出现“草稿与结果”。桌面默认收起，展开后左右分区；手机改为对话与结果切换，输入框保留在聊天区底部。只有一份草稿时不再重复显示“1 个版本”，保留 v1 和未试运行状态。
- 处理记录、模型和用量、草稿说明、日志、下载文件按需展开。保留历史对话、旧草稿、代码预览、使用草稿、下载、浏览器处理及维护入口。
- 发送与停止共用一个位置；等待、失败、停止状态仍可见。主动停止后只保留中性状态，不重复显示通用停止警告；其他错误仍完整显示。轮询保留输入和展开状态，阅读历史时不强制跳到底部。弹窗限制焦点范围，Esc 先关闭代码或结果，再关闭窗口；退出后恢复入口焦点和页面滚动。

只调整对话及正文呈现，没有改变 AI 服务商、模型设置、任务创建、维护和执行规则。没有加入图片素材、语法高亮或新的 UI 框架。弹窗进入 160ms，输入框与按钮反馈 140ms，处理中使用低幅透明度提示；支持减少动态效果设置。

## 独立评审与取舍

按存量界面润色模式做了一轮独立视觉评审，不打分。评审者只收到截图、用户任务与存量设计规范，没有源码和制作过程。采纳了桌面草稿默认收起、删除单版本重复计数的意见，保留开放正文、绿色主操作、焦点外环和真实试运行状态。

评审提到合成回复中“右侧草稿”在手机上不准确。这是隔离示例的历史消息，并非平台固定导航文案；本轮保留回复原文，不用显示层改写模型输出。所有尺寸均提供同名“草稿与结果”入口。未来生成内容仍可能使用方位措辞，不能把本次界面调整描述为已约束所有模型回答。
