# 多宿主机阶段 6 收尾验证

日期：2026-09-21

## 收尾结论

阶段 6 按局域网首版范围完成开发收尾。Agent v0.2.0 已具备当前用户托盘、调度切换、紧凑顶部状态条、结构化进度、停止、紧急接管和交互式会话门控。

键盘鼠标输入限制不进入首版，没有实现或启用任何输入钩子。若阶段 7 真实双机验收证明人工操作会持续干扰任务，再以“独立看门狗、异常自动解除、真实故障恢复”为前提单独立项。

首版不区分桌面任务和后台任务的调度模型。所有远程任务保持单 Agent 串行并显示统一状态条；平台不识别后台任务类型，也不承诺任务脚本不使用桌面。这一保守规则避免在两机验收前引入第二套并发和占用判断。

## 已验证

- Agent 隔离回归 47 项：46 通过，1 条因当前 Windows 账号不能创建符号链接而条件跳过。
- 宿主机接口临时副本回归 57 项全部通过，包含 Agent 0.2.0 ZIP 白名单和缺失桌面组件拒绝下载。
- `pip check`、Python 编译检查和 `git diff --check` 通过；差异检查只有既有 CRLF 转换提示。
- 合成桌面预览可启动；状态条只在任务开始时无激活显示，后续更新不重复抢占浏览器或 Excel 焦点。
- 运行中直接切回非调度会被拒绝；停止保留调度模式，紧急接管在 worker 结束后切为非调度。
- `SPIDERFLY_PROGRESS` 跨输出分片后可形成状态条阶段、页码和采集数量。
