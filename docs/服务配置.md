# 管理配置

管理员进入管理中心，默认显示“管理配置”；上方是团队成员，下方是 API 密钥配置和飞书通知。超级管理员可修改，普通管理员只读，普通成员不显示该入口。运行信息位于“操作审计”页，默认收起。

## 团队成员

超级管理员可新建、编辑或删除成员；新建表单默认收起。账号权限和删除确认沿用现有规则。

## API 密钥配置

填写 DeepSeek 密钥，获取官方模型列表，选择默认模型并保存。余额手动查询，保存成功后查询一次；账户余额不等于 Token 额度。超级管理员按既有授权查看 AI 密钥，其他角色不取得明文。详细规则见 [AI 任务助手](AI任务助手.md#配置与操作)。

## 飞书群通知

默认选择群通知，填写群机器人的 Webhook 地址；机器人开启签名校验时，再填签名密钥。未开启签名校验可留空。保存后只表示本机配置已保存，没有发送或验证消息。

敏感输入不回显，留空保留已有值。若机器人取消了签名校验，勾选“清除已保存的签名密钥”后保存。

## 飞书个人通知

选择个人通知，填写 App ID、App Secret 和接收人的飞书手机号。应用需启用机器人能力，并具有手机号查询和消息发送权限，接收人须在应用可用范围内。手机号用于查询用户 ID，再由应用机器人发送消息，不能只填一个手机号就发送。已有 Open ID 配置可在“收件人类型”中选择。

两种方式的配置分别保留，同时只生效当前保存的方式。切换方式后需要保存；不同时给群和个人各发一份。修改 App ID 时须同时填写对应的 App Secret。官方接口：[通过手机号获取用户 ID](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/contact-v3/user/batch_get_id)、[发送消息](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/im-v1/message/create)。

## 保存和清除

保存不会主动联系飞书；后续任务按自己的成功/失败通知选项发送，运行或维护链路的通知规则保持。保存后新通知读取最新配置，进行中的一次通知使用原配置。

本机飞书配置保存在数据目录 `secrets/feishu.settings.dpapi`，由当前 Windows 账号加密，备份应包含整个数据目录；换电脑或运行账号需重新配置。部署环境中已有任一飞书凭据时整组优先，网页只读，不与本机配置拼接。并行修改冲突时重新加载后再编辑。

“清除配置”会同时删除本机保存的群与个人配置，确认后生效；它不会删除已经发出的消息。损坏配置也可清除后重填。普通接口和审计不记录 Webhook 或密钥，普通管理员不取得手机号。
