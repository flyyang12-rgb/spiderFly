# 已撤销电脑永久删除

“管理中心 → 宿主机 → 全部电脑”中，已撤销电脑显示“永久删除”。确认后移出电脑列表、统计和任务目标选项；原 Agent 无法继续使用旧身份连接。运行记录、日志、产物、环境报告和审计保留，再次使用需重新接入并批准。

## 边界

- 仅管理员可操作，接口校验登录、同源信息和 JSON；普通成员无权删除。
- 待批准、已批准和已拒绝电脑不提供删除；后端同样拒绝。
- 尚有未归档任务绑定时拒绝，包括已停用任务；不会清空目标或自动改为主控。需先修改任务的运行电脑，或删除任务。
- 有未结束运行、状态待确认、升级任务或有效升级占用时拒绝；不能通过删除绕过运行收尾。
- 删除确认前可以取消，提交期间禁止重复提交和关闭。失败保留弹窗及具体原因；丢失响应后可安全重试。
- 不远程卸载 Agent，也不清理另一台电脑上的脚本、环境和业务文件。

## 实现

`DELETE /api/hosts/{id}` 复用管理员写操作权限。一个数据库事务完成校验、清除机器身份/公钥/nonce/已消费接入码、删除标记与审计；重复请求返回同一结果，不重复记录审计。已消费的接入码被删除，不会恢复为可用。

数据库增加 `agent_hosts.deleted_at`。为保持历史运行及升级外键，内部保留只用于历史关联的占位记录和电脑名称，**不是物理清除整行或删除运行历史**；机器标识改为不可注册的占位值，公钥清空，没有恢复入口。普通宿主机读取和机器认证拒绝已删除 ID；只有历史详情允许读取占位。新接入生成不同 Host ID，重新等待批准。Agent 程序和协议无需升级。
