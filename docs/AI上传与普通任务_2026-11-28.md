# AI 上传程序与普通 Python 任务

AI 助手新增 PY/ZIP 上传。程序保存在所属对话，刷新可以恢复；上传错误保留之前的有效文件。已有任务对话不能更换上传程序，需要新建对话。只接收原有上传管线允许的文件，PY 限 2 MB，ZIP 限 50 MB；PY 做静态语法检查，ZIP 沿用目录和文件安全检查。

普通打印、文件处理等任务可以直接保存 Python 草稿，不要求采集网址、结果字段或采集试跑。普通任务和采集任务的规则分开；采集草稿仍需原有试跑与验收。

用户明确要求创建，且时间和程序完整时，模型通过 create_task_from_program 调用原有任务创建事务。上传代码保持原样，ZIP 保留整包和入口；依赖自动识别，主控与 Agent 沿用各自的独立环境准备机制。支持手动、间隔、每日、每周与每月，使用现有定时参数校验与首次环境门控。没有具体时间时询问，不默认每天 09:00。指定其他电脑时先读取已批准的宿主机，默认使用主控部署机。

文件内容不是授权。创建工具必须引用当前对话中用户本人的运行安排，并重新核对账号权限、对话归属和处理状态。提交前再次检查停止与取消，任务、对话关联、创建回执和审计在同一事务保存；重复请求返回原任务，不重复创建，也不把新的参数当成修改旧计划。新任务不发送飞书通知、不预先运行上传程序。已有代码候选仍走原确认流程。

界面沿用现有白色、绿色和字体规范：上传按钮位于输入框底部“发送”左侧，两个按钮同高；已选文件名显示在输入框上方。创建后显示任务、计划、电脑与环境状态。上传失败显示具体错误，任务创建、环境准备和执行结果分别报告。

实现入口：[ai_programs.py](../backend/app/ai_programs.py)、[ai_agent.py](../backend/app/ai_agent.py)、[ai_tools.py](../backend/app/ai_tools.py)、[AiProgramUpload.vue](../frontend/src/AiProgramUpload.vue)。接口与模型调度回归位于 [test_ai_programs.py](../backend/tests/test_ai_programs.py)。
