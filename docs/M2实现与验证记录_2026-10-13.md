HTTP 入口为 `/api/workflows` 定义列表与管理、`/api/workflows/tasks` 可选任务、`/api/workflows/{id}/runs` 接受运行、`/api/workflow-runs` 历史分页、`/api/workflow-runs/{id}` 详情和 `/api/workflow-runs/{id}/stop` 停止。启动需 request_id，编辑需 revision；日期筛选转换为北京时间日期对应的 UTC 半开区间。

## 当前边界

- M2 仅手动触发、主控本机普通 native Python。readonly-v1、collection-v1、drissionpage-v1 专用执行器和绑定远程电脑的任务不能加入首版流程；普通 native 脚本导入 DrissionPage 库不因此被排除。
- 脚本自行读写业务目录或数据库。平台提供执行顺序和独立结果记录，不传递 Python 内存、桌面会话或业务文件。
- 保留旧单任务手动/每日/每周、新单任务 Cron 与局域网 Agent 路由；新增流程没有远程执行、并行 DAG、步骤分支或失败位置恢复。
- M3 整流程 Cron、计划与成员单任务计划的双向冲突规则仍待实施；页面现在只提供手动流程。
- 文件清理与 SQLite 不是同一个原子提交。清理入口在同一数据库写事务内核对活动引用及执行文件删除；删除快照前核对目录归属、符号链接/目录联接和活动轮次，失败保留路径供再次清理。发现损坏或未知收尾证据时保持保护，不猜测释放。
