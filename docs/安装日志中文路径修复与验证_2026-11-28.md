# 安装日志中文路径修复

主控安装任务环境时，“验证解释器”阶段的中文路径出现乱码。业务包实际安装与任务执行正常，问题在子进程输出编码。

[environments.py](../backend/app/environments.py) 的解释器校验使用 Python `-I` 隔离模式，该模式忽略 `PYTHONUTF8` 和 `PYTHONIOENCODING` 环境变量。Windows 子进程按系统编码输出路径，而主控按 UTF-8 解码。校验与环境事实读取命令现在明确传入 `-X utf8`，保留 `-I`，不修改系统编码或用户环境。

[test_environments.py](../backend/tests/test_environments.py) 增加实际环境构建回归：在中文目录内创建 venv，检查保存的安装日志包含真实解释器与环境路径，且不存在 Unicode 替换字符。修复前能复现错误，修复后通过。

隔离后端全套共 861 项，842 通过，19 条件跳过。初次检查使用较新的 FastAPI/Starlette 时，有一项既有宿主机签名用例失败；隔离测试依赖对齐主控当前版本后，该用例与全套检查均通过。未升级主控依赖。

Agent 全套共 104 项，103 通过，1 条件跳过。本次未修改 Agent 或前端源码。

正式主控在空闲时完成全部运行资料、配置与修改前后源码备份，停止原进程并重启；健康检查确认调度、队列、环境与 AI worker 正常。主控依赖版本保持不变。

更新后通过任务中心重新上传未填写依赖的 PY 与 ZIP。PY 自动安装 requests 2.34.2，实跑 #4087，耗时 0.156 秒；ZIP 的子模块导入 yaml，自动安装 PyYAML 6.0.4，实跑 #4088，耗时 0.233 秒。以上为环境就绪后的执行耗时。

两次运行均成功、退出码 0，网页出现“运行成功”。保存的安装日志中，解释器和环境目录的中文路径均与任务运行时上报的真实路径完全一致，不含 Unicode 替换字符；运行日志中文正常、stderr 为空。两个环境路径不同，第三方包从各自环境加载，并通过系统包、用户级包和交叉隔离检查。验收证据下载后，两项临时任务、程序、独立环境与运行记录已通过正常平台删除流程清理。
