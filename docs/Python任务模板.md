# 通用 Python 任务模板

新增流程请优先使用[独立流程目录](../flows/README.md)中的模板和单文件例子。本文下方保留前一阶段的入口说明；包内业务示例继续兼容，但新增业务不再依赖它们。

写新流程时，可以复用[通用入口](../backend/spiderfly_instructions/task.py)，把业务代码放进一个 `process(context)` 函数。公共代码接收平台路径、留存上传文件并保存回执，业务函数负责计算、检查及输出文件。

## 先拿哪个文件

| 用途 | 单个上传文件 | 依赖 | 上传 Excel |
| --- | --- | --- | --- |
| 体验模板，再替换自己的业务代码 | [instruction_python_task_template.py](../examples/instruction_python_task_template.py) | `spiderfly-instructions==0.1.3` | 可不上传 |
| 待处理总金额减去已完成总金额 | [instruction_excel_amount_difference_task.py](../examples/instruction_excel_amount_difference_task.py) | `spiderfly-instructions==0.1.3` | 必须上传 |

管理员先将本地 `spiderfly_instructions-0.1.3-py3-none-any.whl` 放到项目的 `release/instructions/`。在已有“创建任务”页面上传单个入口、填写依赖和选择文件；先用手动触发，关闭测试通知，等待环境就绪后运行。原任务和旧版本不会自动升级。

金额差额默认处理第一张表，使用“状态”“金额”列，比较“待处理”和“已完成”。需要更换条件时，在入口的 `run_flow(...)` 中传入列名或状态，参数见[金额差额流程](Python金额差额示例.md)。这里尚未增加网页业务参数表单。

## 业务代码关心三件事

1. 从 `context.input_file` 读取本次已留存的上传文件；无上传时为 `None`。
2. 把需要下载的文件写到 `context.output_dir`。
3. 完成业务检查后返回 `TaskResult(message="处理说明", code="TASK_DONE")`；失败就抛出异常。

[可复制模板](../examples/instruction_python_task_template.py)已包含这些部分。`run_task(process)` 默认必须上传输入，不需要输入时使用 `run_task(process, require_input=False)`。这是普通 Python 函数，不是第六条注册指令；原五条指令及注册方式不变。

任务模板需要平台提供运行目录；本地直接计算仍使用金额差额流程的命令行。不要把任务模板当作可直接双击的本地脚本。

## 在哪里看结果

在本次运行记录中查看业务说明，再到“本次文件”下载：

- 通用模板：`流程文件/输出/运行说明.txt`。
- 金额差额：`流程文件/输入.xlsx` 和 `流程文件/输出/金额差额.txt`。

金额说明以文字保存精确十进制结果。对测试表 ccc.xlsx，内容是“待处理合计：12.6；已完成合计：12.3；差额：0.3”，并附两组行数和指令调用记录；原 Excel 不改写。

输入完整复制后才执行业务函数。缺少必需上传、复制中断、业务异常或返回值不是 `TaskResult` 都失败；指令异常保留编号、阶段和错误编码。输入已留存时，可以从失败记录下载。回执保存失败时不会打印成功说明。已有回执或同次目录拒绝复用，重新运行由平台生成新的执行记录。

## 范围与验证

入口沿用已有 `result.json` 协议，不自动重试，也不判断业务输出是否正确。具体流程应检查结果后返回成功，文件存在不等于业务成功。进程被平台强制终止时，仍由平台执行器决定状态。

金额差额实现已移入包内的 `example_flows.excel_amount_difference`；旧命令入口转为调用同一实现，因此当前源码需 0.1.3。旧姓名、筛选、均值任务入口仍按原声明运行；以前的 0.1.2 包保留。

2026-09-03 的独立安装环境中，8 项入口测试与6项金额差额测试共14项通过。隔离平台实际创建无需上传、正常金额和非法金额三个任务，执行四次：三次成功，一次按预期失败；6 份文件经带登录校验的 GET/HEAD 下载并与存档逐字节核对，未登录下载被拒绝。原件和前次结果不变，公共临时区清理后文件仍保留。

本次未新增页面或数据库字段，未更新真实服务。安装包及详细验证记录见[维护文档](维护约定与决策记录.md)。
