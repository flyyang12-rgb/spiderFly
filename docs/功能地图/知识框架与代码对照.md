## AI 配置与账户余额

[AiSettings.vue](../../frontend/src/AiSettings.vue) 负责密钥、官方模型列表与默认模型；[AccountBalance.vue](../../frontend/src/features/settings/AccountBalance.vue) 负责手动余额刷新、保存后一次查询、失败保留过期结果与请求失效。超级管理员页面通过 ai_agent.py 的专用 settings/key 读取已存密钥，响应 no-store；其他角色不调用该接口，卸载与会话失效清空显示。本地 DPAPI 保存方式保持。页面调用 [ai_agent.py](../../backend/app/ai_agent.py) 的管理员余额接口，由 [ai_settings.py](../../backend/app/ai_settings.py) 读取当前有效密钥并查询官方账户。余额只在页面内存展示，不进入业务脚本环境。

[remote_maintenance.py](../../backend/app/remote_maintenance.py) 在远程维护收到有效用量后结算预留，未知用量保守保留；[task_versions.py](../../backend/app/task_versions.py) 的 used_budget 将其纳入本机/远程共享维护预算。账户金额和维护 Token 额度分别处理，见[操作说明](../AI任务助手.md#查询-deepseek-余额)。

## AI 收到问题以后

```mermaid
flowchart TD
    Q[用户提问] --> A[ai_agent.py：处理对话]
    A --> K[ai_knowledge.py：初始参考、检索、读章节]
    K --> M[Markdown：索引、原生资料、平台规则]
    M --> A
    A -->|解释用法| R[依据资料回答]
    A -->|DP 创建任务| P[dp_probe.py：排队观察真实页面]
    P --> D[ai_agent.py：生成并保存 Python 草稿]
    D --> C[collection.py：排队试跑并验收]
    C --> N[dp_runtime.py + dp_driver.py：实际执行]
    C --> S[使用草稿保存任务]
    S --> E[execution_queue.py + runner.py：后续运行]
    E --> N
```

例如你问“DP 调试为什么用了别的端口”，对应 [DP 任务](DP任务.md) 的端口条目，检查 config.py、dp_runtime.py 和 dp_driver.py；问“AI 为什么没查资料”，对应 [采集知识库](采集知识库.md)，检查 ai_agent.py、ai_tools.py 和 ai_knowledge.py。

## 手动流程怎么对应代码

```mermaid
flowchart LR
    A[api/workflows.py：管理员启动] --> B[workflows.py：全部步骤文件与参数冻结]
    B --> C[SQLite：流程与步骤持久关联]
    C --> D[workflows.py：当前步骤入队]
    D --> E[execution_queue.py：串行领取]
    E --> F[runner.py：读取冻结快照]
    F --> G[native_process.py：本次进程树与收尾证据]
    G --> H[workflows.py：核对最终结果与收尾]
    H -->|成功且有后续| D
    H -->|失败或停止| I[结束本轮，停止下游]
```

流程快照独立于 AI 配置；恢复入口在 [runtime.py](../../backend/app/services/runtime.py)，串行边界在 execution_queue.py。删除与环境保护由 [environments.py](../../backend/app/environments.py) 查询整轮活动引用，历史摘要由 workflows.py 独立保存。手动路径证据见[M2 记录](../M2实现与验证记录_2026-10-13.md)；M3 调用 workflow_schedules.py 原子登记计划点并复用上述整轮冻结和推进路径，代码、实际页面及 2026-10-14 正式加载证据见[M3 记录](../M3实现与验证记录_2026-10-14.md)。
