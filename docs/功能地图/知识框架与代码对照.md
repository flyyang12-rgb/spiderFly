## AI 收到问题以后

```mermaid
flowchart TD
    Q[用户提问] --> A[ai_agent.py：处理对话]
    A --> K[ai_knowledge.py：初始参考、检索、读章节]
    K --> M[Markdown：索引、原生资料、平台规则]
    M --> A
    A -->|解释用法| R[依据资料回答]
    A -->|DP 创建任务| P[dp_probe.py：排队观察真实页面]
    P --> D[ai_agent.py：生成并保存 Python 草稿]
    D --> C[collection.py：排队试跑并验收]
    C --> N[dp_runtime.py + dp_driver.py：实际执行]
    C --> S[使用草稿保存任务]
    S --> E[execution_queue.py + runner.py：后续运行]
    E --> N
```

例如你问“DP 调试为什么用了别的端口”，对应 [DP 任务](DP任务.md) 的端口条目，检查 config.py、dp_runtime.py 和 dp_driver.py；问“AI 为什么没查资料”，对应 [采集知识库](采集知识库.md)，检查 ai_agent.py、ai_tools.py 和 ai_knowledge.py。
