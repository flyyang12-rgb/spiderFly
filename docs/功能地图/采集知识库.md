# 采集知识库

AI 回答采集问题时，先参考本地知识，再按需要查看具体章节。Scrapling 按 0.4.15 整理；DrissionPage 已导入你提供的 4.1.1.2 本地文档；之前的 4.1.1.4 概要保留版本标注。每篇附工具、接入状态、版本、适用范围和来源。

## 定位和入口

知识库供 AI 查资料、解释用法和比较工具；实际执行仍由平台工具完成。它不保存用户网站业务数据，文档中的例子也不是现场采集结果。

| Scrapling | 已有受控适配，13 个专题 | [概览](../../backend/ai_knowledge/scrapling/overview.md) |
| DrissionPage / DP | 59 篇技术文档、概要及目录；[DP 任务](DP任务.md)说明当前可选执行方案 | [概览](../../backend/ai_knowledge/drissionpage/overview.md) |

问 DrissionPage 时优先查它的资料；比较两者时分别查。找不到章节表示资料不足，不能直接断言工具不支持。DrissionPage 资料覆盖启动与接管、端口与用户目录、标签页、定位与交互、等待、监听、Cookie、请求、下载上传、截图、配置、异常和其他工具对接。

## 回答的依据

讲原理、比较用法可以依据知识回答；判断某个网站是否可采、实际有多少条，需要读取现场证据。原生 Scrapling 支持某个功能，不代表平台已经开放，AI 需要说明两者的区别。

当前工作区已接入本地检索与自动附带知识，正式服务尚未重启加载。代码位置和更新方式见 [知识库维护](../开发/采集知识库维护.md)。
