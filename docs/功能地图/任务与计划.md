# 任务与计划

负责保存“运行什么、什么时候运行”。页面入口是任务中心和管理中心的创建任务。

## 操作流程

上传 Python 脚本、声明依赖 → 准备环境 → 保存任务设置 → 手动执行或等待计划触发。

## 关键规则

- 任务包含名称、说明、脚本、执行环境、超时、通知和触发规则。
- 当前主要页面提供手动、每日、每周；后端另外支持单次和间隔触发，不能视为页面已有入口。
- 计划使用北京时间。停用后不再正常触发计划；停止正在执行的任务使用运行中心的停止操作。
- 每次执行单独生成执行记录；任务设置和某次运行结果分开保存。
- 更换脚本交给“版本与修复”，实际执行交给“运行与结果”。

常见提问：“每天几点执行在哪里改？”“更换脚本会不会影响计划？”
