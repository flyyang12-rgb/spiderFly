# 系统与环境

负责准备任务运行条件。页面入口包括创建任务时的环境状态，以及“管理中心 → 管理配置”中的 API 密钥配置和飞书通知；折叠运行信息位于“操作审计”页；宿主机部署另见使用说明。

## 操作流程

准备宿主机与配置 → 按脚本依赖准备 Python 环境 → 启动服务 → 向任务执行、AI 和通知提供支持。

## 关键规则

- 普通 Windows 任务环境与 AI 受限验证环境分开准备，能力不相同。
- 管理配置在团队成员下方集中 API 密钥配置与飞书通知；操作审计同页展示只读运行信息，按需展开；调用和维护预算仍由后台管理。飞书支持群机器人和个人应用通知，只生效选中的渠道，保存不会发送消息。
- 超级管理员可修改飞书并明文查看已保存凭据，局域网访问规则相同；管理员只读状态。部署环境整组优先；本机配置 DPAPI 加密，签名单独清除，清空配置需确认。换电脑或 Windows 账号后重新配置。具体字段与权限见[服务配置说明](../服务配置.md)。
- 数据库、上传脚本、执行产物、配置和密钥属于运行资料，不能当作源码一起覆盖。
- 拉取代码不等于运行服务已经加载新代码；更新代码、重启和业务验证分别确认。
- 备份、换电脑和恢复按 [使用说明](../../使用说明.md) 执行。

常见提问：“为什么环境准备失败？”“更新后需要重启吗？”“通知在哪里配置？”

## 自动依赖准备

上传单个 Python 文件或 ZIP 时，平台静态识别导入并自动生成安装清单。已知别名使用安装包映射，条件导入一并准备，其他普通英文模块名交由安装器解析同名包。版本约束优先，环境失败如实显示安装日志。界面不要求逐项填写包名。

主控的业务 venv 位于 data/envs 下的受管目录，按程序及修订隔离。Agent 使用原有冻结包环境缓存，收到新的依赖清单后自动创建或复用对应环境，安装成功并核验后才运行。操作系统软件和项目漏传文件不属于 Python 包安装范围。

主控安装器的隔离解释器校验明确使用 UTF-8 输出，避免 Windows 中文目录在安装明细中乱码；保留原有独立环境与隔离模式。实现与回归见[安装日志中文路径修复](../安装日志中文路径修复与验证_2026-11-28.md)。
