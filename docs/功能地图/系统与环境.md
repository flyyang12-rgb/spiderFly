# 系统与环境

负责准备任务运行条件。页面入口包括创建任务时的环境状态，以及“管理中心 → 管理配置”中的 API 密钥配置和飞书通知；折叠运行信息位于“操作审计”页；宿主机部署另见使用说明。

## 操作流程

准备宿主机与配置 → 按脚本依赖准备 Python 环境 → 启动服务 → 向任务执行、AI 和通知提供支持。

## 关键规则

- 普通 Windows 任务环境与 AI 受限验证环境分开准备，能力不相同。
- 管理配置在团队成员下方集中 API 密钥配置与飞书通知；操作审计同页展示只读运行信息，按需展开；调用和维护预算仍由后台管理。飞书支持群机器人和个人应用通知，只生效选中的渠道，保存不会发送消息。
- 超级管理员可修改飞书，管理员只读状态。部署环境整组优先；本机配置 DPAPI 加密，敏感字段留空保留，签名单独清除，清空配置需确认。换电脑或 Windows 账号后重新配置。具体字段与权限见[服务配置说明](../服务配置.md)。
- 数据库、上传脚本、执行产物、配置和密钥属于运行资料，不能当作源码一起覆盖。
- 拉取代码不等于运行服务已经加载新代码；更新代码、重启和业务验证分别确认。
- 备份、换电脑和恢复按 [使用说明](../../使用说明.md) 执行。

常见提问：“为什么环境准备失败？”“更新后需要重启吗？”“通知在哪里配置？”
