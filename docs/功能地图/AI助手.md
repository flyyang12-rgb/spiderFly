# AI 助手

负责把需求变成脚本草稿，帮助探索网页和修改任务。页面入口是 AI 助手。

当前工作区能力及正式主控加载状态见 [CONTEXT](../../CONTEXT.md)；GitHub 发布状态另按对应提交与发布记录核对。

2026-10-15 已实现 DeepSeek 官方列表与默认模型选择，并由正式主控加载；配置操作、隔离回归、真实页面及未执行的真实模型验证分别见[实现记录](../DeepSeek模型列表选择实现与验证_2026-10-15.md)。

采集相关问答先参考 [采集知识库](采集知识库.md)，覆盖 Scrapling 原理、平台用法与常见报错，并附版本和来源。

## 操作流程

描述需求 → 助手分析或探索 → 保存脚本草稿 → 在支持的环境试跑 → 创建任务或提交修改候选。

正文支持安全的 Markdown 排版，完整保留回复。顶部“草稿与结果”按需展开草稿与探索结果，窄屏切换为结果页；处理记录和技术详情默认收起。发送时只显示停止操作，未试运行的草稿如实标记。前端入口见 [AiAssistant.vue](../../frontend/src/AiAssistant.vue)、[正文组件](../../frontend/src/AiMessageContent.vue) 和 [安全渲染](../../frontend/src/lib/aiMarkdown.js)，验证见[界面优化记录](../AI助手界面优化_2026-10-15.md)。

## 关键规则

- 日常执行已保存脚本不调用模型；模型用于对话、生成和故障维护。
- 超级管理员在管理中心的“管理配置 → API 密钥配置”填写 DeepSeek 密钥、获取官方模型列表，再选一个主控共用的默认模型；保存前重新核对同一有效密钥的官方列表。管理员只读配置并使用自己的对话，普通成员不能使用 AI 入口。环境密钥生效时页面说明来源并禁止网页替换；目录查询不保存新密钥、不生成内容，也不证明 tools 或业务验收通过。调用与维护预算仍由后台和 API 约束。用户授权超级管理员直接查看已保存密钥，其他角色不返回明文；本地仍加密保存。完整配置说明见 [AI 任务助手](../AI任务助手.md#配置与操作)。
- 生成或修改脚本，需要把字段、筛选等要求落实到代码；口头答复不算完成。
- 浏览器探索会话与定时脚本的登录状态不同，探索成功不等于定时运行已经可用。
- 试跑使用准备好的支持环境和串行队列；readonly-v1 / collection-v1 是受限环境，已授权原生 DP 使用宿主机账号权限，不是 WSL 沙箱。不保证任意 Windows 桌面或登录浏览器脚本都能自动验证。
- 人工上传或 AI 主动修改现有任务先形成候选，旧本机链路验证通过后等待用户确认使用，详见“版本与修复”；执行失败后的旧本机独立任务维护沿用验证、自动启用和至多一次重跑授权。新 Cron 的维护和一次重跑关联原轮，期间跳过新计划；工作流步骤不自动修复或重跑，远程候选由管理员确认后在原宿主机新建运行。

常见提问：“助手会不会每次运行都重新写脚本？”“网页登录能不能用于定时任务？”
