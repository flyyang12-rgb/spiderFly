# 运行与结果

负责把任务排队执行，并保存这一次发生了什么。页面入口是运行中心；工作台汇总近期情况。

## 操作流程

收到执行请求 → 排队 → 检查宿主机 → 运行脚本 → 保存状态、日志和产物 → 按设置通知。

## 关键规则

- 一台 Windows 同一时间执行一个任务；维护验证和采集试跑也共用串行队列。
- 排队中的记录可以取消，正在执行的记录使用停止操作；两者含义不同。
- 运行记录保留成功、失败、超时等实际结果。失败后修好了，原失败记录仍保留。
- 历史记录由后端筛选和分页；日志、错误与可下载产物在执行详情中查看。
- 业务脚本负责保存文件、关闭自己创建的 Excel 或浏览器；平台不替业务脚本保存桌面文件。

常见提问：“为什么还在排队？”“这次失败原因和输出文件在哪？”
