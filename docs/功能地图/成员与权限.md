# 成员与权限

负责识别使用者、限制操作范围和记录管理行为。页面入口是登录、修改密码，以及管理中心的管理配置和操作审计。团队成员位于管理配置页上方，API 密钥与飞书配置在下方；操作审计页同放运行信息和操作记录。

## 操作流程

登录 → 后端检查身份和权限 → 执行业务操作 → 对需要审计的操作保存记录。

## 关键规则

- 管理操作由后端验证权限，隐藏页面按钮不能替代权限校验。
- 任务归属人与本次运行发起人分开记录；他人操作不会改变任务归属。
- 成员停用、删除和密码变更由账号模块处理；历史业务记录按已有规则保留。
- 账号权限与 AI 模型权限涉及不同操作，不能简单理解成“登录后都能改”。
- 操作记录由后端分页查询全部历史，每页 10 条，按最新在前排序；显示总条数、页码和上一页/下一页。刷新保留当前页，读取失败保留上次记录；管理员及超级管理员可查询。

常见提问：“普通成员能操作哪些功能？”“谁触发了这次运行？”
