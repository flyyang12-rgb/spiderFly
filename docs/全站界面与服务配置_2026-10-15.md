## 飞书配置

默认群通知，只显示 Webhook 地址和可选签名密钥；个人通知展开 App ID、App Secret、手机号，Open ID 兼容项折叠。手机号先换取用户 ID，再使用应用发送消息，仍需应用机器人、通讯录查询、消息权限和可用范围。具体操作见 [服务配置](服务配置.md)。

新增 `GET/PUT/DELETE /api/settings/feishu`：管理员可读状态，超级管理员保存和清除，普通成员拒绝。Webhook 和两类密钥不回显；手机号只向超级管理员提供。整包 DPAPI 保存于数据目录 `secrets/feishu.settings.dpapi`，原子替换，revision 不一致返回 409；留空保留敏感值，签名可独立清除，完整清除涵盖两种配置并要求确认。两种方式分别保留但只生效当前保存的一种。修改 App ID 必须同步提供对应密钥。

部署环境中任一飞书凭据存在时整组优先、网页只读；保持原 .env 群优先及应用模式，不拼接不同来源的接收对象。保存不联系飞书、不宣称已连接；新通知器读取新配置，一次进行中的通知保留其原配置和 Token 缓存。任务、流程、维护的通知选项和规则保持。普通设置、审计、业务环境不增加原始密钥。AI 明文权限、模型目录、余额和预算规则沿用既有实现。
