# README 图示

这些静态 SVG 用于项目首页，均为可编辑矢量源文件，没有远程字体、脚本、生成式图片或动画。

- 读者：需要共享 Python 自动化的 Windows 小团队。
- 核心价值：成员用浏览器提交，单台宿主机排队运行，日志与文件统一查看。
- 示例依据：[订单筛选脚本](../../examples/instruction_excel_filter_task.py) 和 [样本说明](../../docs/平台筛选示例.md)。订单为虚构数据，图示不是产品截图或业务运行记录。
- 首次体验：上传订单筛选脚本及模板，运行后下载两条待处理订单。
- 视觉方向：使用产品的绿色标记、队列路径、输入输出数据表。

| 图示 | 用途 |
| --- | --- |
| hero.svg | 项目名、单机共享定位、串行处理路径 |
| excel-example.svg | 三行输入到两行输出的样本对照 |
| workflow.svg | 正常执行、故障维护与人工版本确认的区别 |

颜色沿用产品：背景 #e9f6ee / #f7f8f6，主色 #009139，深色 #123422，正文 #292b28，辅助 #647269，失败分支 #e16b51。字体使用 Segoe UI、Microsoft YaHei、PingFang SC 与系统 sans-serif；统一 1200 单位宽，标题 40 以上，主要标签 24–34，18–22 用于辅助说明。品牌图形来自现有 favicon。

图片在 900px 与 360px 宽度渲染核对，带固定背景以兼容深浅色页面。手机上图示细节可结合相邻 Markdown 阅读，安装命令和必要说明均保留为正文。图片引用与 SVG 基础检查使用 beautify-github-readme 的 audit_readme.py。
